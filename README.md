# LearnBox

인터넷 자료를 **허용된 시간에만** 조금씩 모으고, 내 파일도 가져와서, **학습한 파일 안에서 검색**하고, 그 자료로 **내 모델을 학습**해 **질문에 답하게** 하는 개인용 도구입니다.
끝낼 때는 **배운 내용을 파일로 내보내고 알림으로 알려 주며**, 관리자는 결과를 **외장 저장장치(USB·외장 SSD·HDD)** 에도 저장할 수 있습니다.
PC와 휴대폰이 **같은 화면, 같은 기능, 같은 데이터**를 씁니다.

```
[PC: LearnBox 엔진] ── 수집(허용 시간대만) ─┐
   ├ 내 파일 가져오기 (txt·md·csv·json·pdf·docx …) ─┤→ 정제 → 검색 인덱스(SQLite FTS5 + 임베딩)
   │                                                ├→ 학습: 소형 AI 모델(처음부터) / LoRA(공개 모델 + 내 자료)
   │                                                ├→ 자율 학습 ─ 학습 종료 ─→ 결과 파일 + ZIP + 알림
   │                                                └→ 관리자 내보내기 → 외장 저장장치
   ├── PC 브라우저        ┐
   └── 휴대폰 브라우저    ┘ 같은 웹 화면 (같은 Wi-Fi)
         └ 기기에 저장: 자료 사본(오프라인 검색) + 소형 AI 모델(온보드: 인터넷 없이 실행)
```

## 기능

| 기능 | 설명 |
|---|---|
| 지정 링크 학습 | 링크를 넣으면 본문을 가져와 저장·색인. 같은 사이트 안 링크를 1~2단계 따라갈 수 있음 (한글이 들어간 주소도 됨). 위키백과의 메뉴·언어 목록·분류·편집 링크·수식 원문(LaTeX)은 본문에서 뺌 |
| 실시간 검색 수집 | 검색어로 웹을 검색하고 결과 페이지를 가져와 저장. 위키백과(키 불필요), SearXNG, Brave Search API 지원 |
| **내 파일 가져오기** | txt · md · csv · tsv · json · jsonl · html · xml · pdf · docx · srt · log 를 끌어다 놓거나 폴더째 가져오기. 같은 파일은 한 번만 저장 |
| **학습한 파일 안에서 검색** | 키워드(한국어 부분 일치) + 의미 검색 통합, `"구문"` · `-제외어`, 자료 종류 필터, 핵심 문장, 문서 보기(일치 위치 강조) |
| **네 가지 답변 방식** | 소형 AI 모델 · LoRA 모델 · 온라인 모델(Claude) · 온보드 모델(휴대폰/브라우저 안에서 실행) + 검색만 |
| **모델 크기 설정** | 나노~라지 5단계 + 직접 설정. 입력하는 즉시 파일 크기·메모리·실행 가능 기기를 예상해 보여 줌 |
| **자율 학습** | 허용 시간대에 스스로 조금씩 수집하고(주제도 스스로 찾음), 새 자료가 모이면 이어서 학습 |
| **학습 종료 → 결과 파일 + 알림** | 마지막 학습 후 JSONL · CSV · Markdown · TXT · 검색 색인 · 모델(ONNX 포함) · 보고서 · ZIP으로 내보내고 앱 알림으로 알려 줌 |
| **휴대폰/PC 성능 대응** | PC의 CPU·메모리·GPU·TPU로 모델 크기와 학습량을 추천하고 학습 장치를 자동으로 고르며(코랩 TPU v5e-1 학습 지원), 휴대폰은 메모리·코어로 모델 형식(int8/fp32), 자료 사본 크기, 생성 길이를 자동 조절 |
| 수집 시간 제한 | 설정한 요일·시간대에만 인터넷 접속. **요청 하나하나마다** 시각을 확인해 시간이 끝나면 즉시 멈춤 |
| 수집 예절·안전 | robots.txt 준수, 사이트별 요청 간격, 허용/차단 도메인, 내부망 주소 차단, 페이지 크기 제한 |
| 외장 저장 내보내기 | **관리자만**. 자료·인덱스·모델·말뭉치를 복사하고 파일별 SHA-256(manifest.json) 기록, 감사 기록 남김 |
| 무결성 검사 / 가져오기 | 내보낸 폴더 검증, 다른 PC로 가져오기 |
| **학습 일시정지 · 중간 저장 · 이어서 재개** | PC 학습을 기본 10분마다 중간 저장하고, 일시정지/재개/지금까지 저장하고 끝내기. 저장장치가 빠지거나 전원이 나가도 마지막 저장 지점부터 이어서 재개 ([자세히](#학습-일시정지--중간-저장--이어서-재개)) |
| **휴대폰에서 직접 학습** | 나노급 글자 단위 GPT를 브라우저가 직접 학습(PC 모델에서 이어서 / 처음부터), 벤치마크·체크포인트·발열/배터리 보호, 결과를 PC로 올리기 |
| 오프라인 | 휴대폰에 자료 사본과 모델을 저장해 인터넷 없이 검색·답변 |

## 설치와 실행 (PC)

Python 3.10 이상이 필요합니다.

**간단 실행**
- Windows: `start-windows.bat` 더블클릭
- Mac/Linux: `./start.sh`
- Windows에서 GPU로 학습하려면: 먼저 `setup-gpu-windows.bat`을 한 번 실행한 뒤 `start-windows.bat`을 실행합니다. NVIDIA GPU가 있으면 CUDA용 PyTorch를, NVIDIA가 없고 Intel Arc GPU가 있으면 Intel GPU(XPU)용 PyTorch를 설치합니다(Intel Arc는 아직 실기기로 확인하지 못함). `start-windows.bat`만 쓰면 CPU용 PyTorch가 설치됩니다.
- TPU 런타임(코랩 TPU 등): `./start.sh`는 학습 패키지를 설치한 뒤 `python -m learnbox.setup_accel`을 자동으로 실행합니다(TPU가 아니면 건너뜀). 이미 `.venv`가 있으면 직접 실행하세요. 코랩은 [코랩 매뉴얼](docs/COLAB_MANUAL.md)을 보세요.

처음 실행할 때 설치를 하고 PIN 두 개를 정합니다.
- **사용자 PIN** (4자 이상): 검색, 질문, 파일 가져오기, 수집, 진행 상황 보기, 알림
- **관리자 PIN** (6자 이상): 위 기능 + 모델 학습, 자율 학습 시작/종료, 결과 파일 받기, 외장 저장 내보내기, 설정, 문서 삭제, 감사 기록

**직접 실행**
```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt            # Windows: .venv\Scripts\pip   (PDF 가져오기용 pypdf 포함, 작음)
.venv/bin/pip install -r requirements-train.txt      # 학습 · 의미 검색 · 온라인 모델 (선택, 수 GB)
.venv/bin/python -m learnbox.setup_accel             # TPU 런타임이면 TPU 패키지 설치, 아니면 건너뜀
.venv/bin/python -m learnbox init                    # PIN 설정
.venv/bin/python -m learnbox serve --lan             # 서버 실행
```

GPU용 PyTorch는 `requirements-train.txt`보다 **먼저** 설치합니다. 어떤 명령을 쓸지 모르겠으면 `python -m learnbox.setup_accel --torch-build`가 이 PC의 GPU에 맞는 설치 명령을 알려 줍니다(NVIDIA: CUDA 12.6, Intel Arc: XPU, AMD: ROCm(Linux만), Mac: 기본 torch 그대로).

| 패키지 파일 | 들어 있는 것 | 없으면 |
|---|---|---|
| `requirements.txt` | tzdata(Windows), pypdf | 수집·검색·웹 화면은 그대로 쓰고, PDF만 못 가져옴 |
| `requirements-train.txt` | torch, transformers, peft, onnx, onnxscript, **onnxruntime**, **anthropic** (TPU 패키지는 들어 있지 않음) | 소형 AI/LoRA 학습, 의미 검색, 온라인 모델을 쓸 수 없음 (나머지는 정상) |
| `requirements-tpu.txt` | `torch_tpu`(0.2.0 이상) + CPU용 torch. TPU 런타임 전용, Linux x86_64, Python 3.11 이상 | TPU 대신 CPU로 학습 (안내 문구 표시) |
| `requirements-tpu-xla.txt` | torch 2.9.0 + `torch_xla[tpu]` 2.9.0 (지원 종료). Python 3.10~3.12에서 `torch_tpu`를 쓸 수 없을 때만 | 위와 같음 |

- 두 TPU 파일은 직접 설치하지 말고 `python -m learnbox.setup_accel`을 쓰세요. pip의 조건 표시로는 TPU가 있는지 알 수 없어서, 이 도우미가 TPU 런타임(PCI의 구글 TPU 칩, 환경변수)을 확인했을 때만 설치합니다.
- `torch_tpu`가 이미 있으면(코랩 TPU v5e 기본) "TPU 준비됨"만 출력하고 아무것도 설치하지 않습니다. `torch_tpu`가 있으면 `torch_xla`는 절대 설치하지 않습니다(torch가 2.9로 내려가 `torch_tpu`가 깨짐).
- 옵션: `--check`(설치하지 않고 상태만 JSON으로, 종료 코드 0 준비됨 · 2 설치 필요 또는 불가 · 1 TPU 아님), `--dry-run`(실행할 명령만), `--force`(TPU 신호가 없어도 시도), `--backend auto|torch_tpu|torch_xla`, `--torch-build`(위).

실행하면 접속 주소가 나옵니다.
```
LearnBox 실행 중: http://127.0.0.1:8750
  휴대폰(같은 Wi-Fi)에서 접속: http://192.168.0.12:8750
```

## 화면 구성

| 탭 | 내용 |
|---|---|
| 검색 | 검색창 · 답변 방식(검색만/소형 AI/LoRA/온보드/온라인) · 자료 종류 · 검색 방식 · 핵심 문장 · 답변과 인용 · 문서 보기 · 이 기기에 저장(오프라인 사본) |
| 자료 | 파일 가져오기 · 링크 수집 · 실시간 검색 수집 · 예약 목록 · 문서 목록 |
| 학습 | 기기 성능과 추천 · **자율 학습** · 소형 AI 모델 학습(크기 설정, 장치) · LoRA 학습(장치, 정밀도) · 의미 검색 색인 · Q&A 학습 데이터 · 학습 결과 파일 |
| 모델 | 모델 카드(크기·손실·단계·파일) · 이 기기로 받기 · 이 기기에서 실행(온보드) · PC에서 생성 |
| 작업 | 진행 중/끝난 작업 · 학습 일시정지/재개/지금까지 저장하고 끝내기 · 마지막 중간 저장 · 끊긴 학습 이어서 재개 |
| 관리 (관리자) | 외장 저장 내보내기 · 설정(온라인 모델, 의미 검색, 자율 학습 기본값, 학습 중간 저장 …) · 감사 기록 |

상단의 **종 모양 알림**에는 학습 종료 같은 소식이 쌓입니다(읽지 않은 수 표시, 15초마다 확인). 학습이 끝나면 화면에 안내가 뜨고, 허용했다면 브라우저 알림도 보냅니다.

## 자료 모으기

- **지정 링크**: 링크를 넣고 깊이(0~2)를 고릅니다.
- **실시간 검색 수집**: 검색어를 넣으면 검색 결과 페이지를 가져옵니다. 제공자는 [관리] 탭에서 고릅니다(위키백과/SearXNG/Brave).
- **내 파일 가져오기**: [자료] 탭에 파일을 끌어다 놓거나 고릅니다(여러 개 가능, 파일마다 진행 상황 표시). 관리자는 PC의 폴더 경로를 넣어 폴더째 가져올 수도 있고, 명령줄은 `python -m learnbox ingest <경로>`입니다.

  | 형식 | 처리 |
  |---|---|
  | txt · md · srt · log | 글자 코드(UTF-8/CP949) 자동 판별, 한 파일 = 문서 하나 |
  | csv · tsv | 표 전체를 문서 하나로 (각 행은 `머리글: 값` 줄) |
  | json · jsonl | `text`·`content`·`body`·`article` 칸이 있는 기록이면 기록 하나 = 문서 하나 |
  | html · xml | 본문 글자만 뽑음 |
  | pdf | 글자가 들어 있는 PDF만 (스캔 이미지는 안 됨, `pypdf` 필요) |
  | docx | 문단 글자 |

  파일 크기 상한은 기본 50MB(`ingest.max_file_mb`)입니다. 같은 내용의 파일은 이름이 달라도 한 번만 저장됩니다. LearnBox 자신의 데이터 폴더는 가져오지 않습니다.
- **수집 시간 제한**: [관리] 탭에서 요일·시간대를 정합니다. 시간이 끝나면 진행 중이던 수집도 즉시 멈춥니다.
- **예약 수집**: 등록한 검색어·링크를 허용 시간대에 정해진 간격으로 하나씩 수집합니다(`auto_collect`). 자율 학습이 진행 중일 때는 자율 학습이 같은 일을 대신합니다.
- **위키백과 등에서 `HTTP 429`가 나올 때**: 서버가 요청이 너무 많다고 거절한 것입니다. LearnBox는 서버가 알려 준 시간(Retry-After)이 60초 이내이면 기다렸다가 한 번만 다시 시도하고, 그 뒤에도 거절되면 작업이 실패로 표시됩니다. 위키백과처럼 요청자를 확인하는 사이트는 `data/config.json`의 `user_agent`에 **본인의 연락처(이메일이나 웹 주소)** 를 넣어 달라고 요구합니다. 예: `"LearnBox/2.0 (개인 학습 도구; 연락처: me@example.com)"`

## 학습한 파일 안에서 검색

검색은 이 도구의 중심 기능입니다. 수집한 웹 문서와 가져온 파일이 한 곳에서 검색됩니다.

- **검색어 문법**: 여러 낱말은 모두 들어간 문서를 먼저 보여 줍니다. `"인공 신경망"`처럼 따옴표로 묶으면 그 구문 그대로, `-요리`처럼 앞에 `-`를 붙이면 그 낱말이 든 문서를 뺍니다. 한 글자·두 글자 낱말도 찾습니다. 모두 포함한 문서가 없으면 조사를 뗀 낱말로 넓혀서 찾습니다(자연어 질문 대응).
- **자료 종류 필터**: 전체 · 웹(지정 링크) · 검색수집 · 파일 · 자율(자율 학습이 모은 것).
- **검색 방식**: 통합(키워드 + 의미) · 키워드 · 의미. 의미 검색은 임베딩 색인이 있을 때 쓰이고, 없으면 키워드로 자동 대체됩니다. 통합은 두 순위를 합쳐(RRF) 문서당 가장 알맞은 부분 하나를 보여 줍니다.
- **핵심 문장**: 결과에서 질문과 가장 겹치는 문장 몇 개를 뽑아 출처와 함께 보여 줍니다.
- **문서 보기**: 결과를 누르면 문서 전체와 일치한 곳이 강조되어 나오고 **이전/다음 일치**로 옮겨 다닙니다.
- **의미 검색 색인 만들기**: [학습] 탭 버튼 또는 `python -m learnbox index-embeddings`. 기본 모델 `intfloat/multilingual-e5-small`(약 0.5GB)을 처음 한 번 내려받습니다. 새 자료를 넣은 뒤 다시 누르면 새 부분만 추가됩니다. [관리] 탭에서 끌 수 있습니다.

## 답변 방식 (질문하기)

[검색] 탭에서 답변 방식을 고르고 질문하면, 학습한 자료에서 먼저 근거를 찾은 뒤 그 근거로 답합니다. 답변의 `[1]` `[2]` 번호를 누르면 근거 자료로 이동합니다.

| 방식 | 어디서 실행 | 필요한 것 | 특징과 한계 |
|---|---|---|---|
| **검색만** | PC | 없음 | 핵심 문장을 출처와 함께 보여 줌. 가장 정확하고 가볍다 |
| **소형 AI 모델** | PC | `requirements-train.txt`, 학습한 소형 모델 | 내 자료만으로 **처음부터** 학습한 글자 단위 GPT. 가장 알맞은 문장에 이어서 글을 씀. 문체는 닮지만 **사실을 지어낼 수 있음** |
| **LoRA 모델** | PC | `requirements-train.txt`, 학습한 LoRA 어댑터 | 공개 모델(Qwen2.5) + 내 자료 추가 학습. 검색된 자료를 근거로 질문에 답하고 인용 번호를 붙임. CPU에서는 느림 |
| **온보드 모델** | **휴대폰/PC 브라우저 안** | 모델과 자료 사본을 기기에 저장 | **인터넷 없이** 동작. 기기 안 검색 + 소형 AI 모델 이어 쓰기. 처음 한 번 실행 엔진(onnxruntime-web)을 인터넷에서 받음 |
| **온라인 모델** | Anthropic 서버 | API 키 | 검색된 자료만 근거로 답하고 **문장별 인용**을 붙임. 가장 똑똑하지만 **자료 일부가 외부로 전송되고 비용이 듦** ([온라인 모델 설정](#온라인-모델-설정-claude-api) 참고) |

## 모델 크기 설정

[학습] 탭의 **소형 AI 모델 학습**에서 크기를 고르면 파일 크기·메모리·실행 가능 기기가 바로 계산됩니다. `자동`은 이 PC의 성능에 맞는 크기를 고릅니다.

| 크기 | 차원/층/헤드/문맥/글자 수 | 파라미터 | 파일 (fp32 / int8) | 학습 메모리(배치 32) | 알맞은 기기 |
|---|---|---|---|---|---|
| 나노 `nano` | 128 / 2 / 4 / 128 / 2000 | 약 67만 | 2.6MB / 0.9MB | 약 0.2GB | 저사양 휴대폰 |
| 미니 `mini` | 256 / 4 / 4 / 192 / 3000 | 약 398만 | 15.2MB / 4.6MB | 약 0.7GB | 고사양 휴대폰 |
| 스몰 `small` | 384 / 6 / 6 / 256 / 4000 | 약 1,228만 | 46.9MB / 13.3MB | 약 1.8GB | PC (CPU) |
| 베이스 `base` | 512 / 8 / 8 / 384 / 6000 | 약 2,849만 | 108.7MB / 30.3MB | 약 4.6GB | PC (GPU) |
| 라지 `large` | 768 / 12 / 12 / 512 / 8000 | 약 9,159만 | 349.4MB / 93.7MB | 약 12.8GB | 고성능 GPU (VRAM 16GB 이상) |
| 직접 설정 `custom` | 차원 32~2048, 층 1~48, 헤드 1~32, 문맥 16~2048, 글자 100~20000 | 계산됨 | 계산됨 | 계산됨 | 차원은 헤드 수로 나누어떨어져야 함 |

- 휴대폰에서 직접 실행(온보드)하려면 **나노나 미니**로 학습하세요. 큰 모델은 PC에서만 쓰기 좋습니다.
- 학습한 모델은 `model.pt`(PyTorch), `model.onnx`(fp32), `model.int8.onnx`(int8, 약 1/3 크기), `vocab.json`, `info.json`으로 저장됩니다. ONNX는 만든 뒤 PyTorch 결과와 비교해 검증합니다.
- **이어 학습**: 모델을 고르면 그 모델에서 이어서 학습합니다(구조가 같아야 하고 단계 수가 누적됩니다). 새로 나타난 글자는 `<unk>`로 처리됩니다.
- **한계**: 글자 단위 작은 모델이라 수집 자료의 문체를 흉내 내는 수준입니다. 사실 확인은 검색 결과(출처)를 보세요.

### LoRA 학습 (공개 모델 + 내 자료)

- [학습] 탭 또는 `python -m learnbox train-lora --max-steps 200`
- 수집·가져온 자료로 말뭉치(`data/datasets/corpus-*`)를 만들고, 기반 모델에 LoRA 어댑터를 학습해 `data/models/lora-*`에 저장합니다. Q&A 데이터(`data/datasets/qa.jsonl`)가 있으면 함께 학습합니다(기본 켜짐).
- 학습 전후 **평가 손실**을 기록합니다. 값이 내려가면 내 자료의 문체·용어에 더 맞춰졌다는 뜻입니다.
- 크기 예상: 기반 모델과 LoRA 설정을 고르면 필요 RAM/VRAM과 어댑터 크기를 보여 줍니다(`python -m learnbox estimate --kind lora ...`).

| 기반 모델 | 권장 RAM / VRAM | 라이선스 |
|---|---|---|
| Qwen/Qwen2.5-0.5B-Instruct (기본) | 4GB / 2GB | Apache-2.0 |
| Qwen/Qwen2.5-1.5B-Instruct | 8GB / 4GB | Apache-2.0 |
| Qwen/Qwen2.5-3B-Instruct | 14GB / 8GB | Qwen Research (**비상업**) |
| Qwen/Qwen2.5-7B-Instruct | 30GB / 16GB | Apache-2.0 |

다른 Hugging Face 모델 id를 직접 입력할 수도 있습니다. **모델마다 라이선스가 다르니** 배포 전에 확인하세요. 처음 실행 시 기반 모델을 내려받습니다(0.5B 모델 약 1GB). 한 번 받은 뒤에는 인터넷 없이도 학습·답변이 됩니다.

**정밀도 (LoRA)** — 기본값은 `auto`입니다. 따로 정하지 않아도 bf16을 지원하지 않는 GPU(T4 등)는 fp16으로 학습해 메모리를 아낍니다.

| 값 | 동작 |
|---|---|
| `auto` (기본) | bf16을 하드웨어로 지원하는 GPU(A100·L4 등)는 bf16, 지원하지 않는 GPU(T4 등)는 **fp16 혼합 정밀도 + 기울기 스케일러**. T4에서 3B도 `LEARNBOX_AMP=fp16` 없이 fp16으로 학습됩니다 |
| `fp16` | fp16 혼합 정밀도. 예전에 쓰던 `LEARNBOX_AMP=fp16`은 지금은 `auto`와 같은 결과 |
| `off` | 예전 동작 그대로 (최신 torch에서 T4는 bf16 에뮬레이션, 아주 오래된 torch에서는 float32) |
| `fp32` | float32로 학습 |

- 정하는 순서: 학습 요청([학습] 탭 LoRA 폼의 **정밀도** 선택, `train-lora --amp`) → 환경변수 `LEARNBOX_AMP` → 설정 `lora_training.amp` → `auto`. 폼에서 '자동'을 고르면 환경변수와 설정을 따릅니다.
- 웹에서 시작하는 학습은 서버가 정밀도를 정하므로, 환경변수는 `serve`를 실행할 때 붙여야 합니다(예: `LEARNBOX_AMP=off python -m learnbox serve`).
- TPU는 bf16으로 학습합니다(fp16 없음, `fp32`를 고르면 float32). Mac(mps)·CPU는 정밀도 설정을 쓰지 않습니다. 소형 AI 모델은 정밀도 설정을 받지 않고 GPU에서 예전처럼 자동 혼합 정밀도를 씁니다.
- fp16에서 손실이 nan/inf여서 건너뛴 단계가 **20번 연속**이면 체크포인트를 저장하고 "fp16 학습에서 손실이 20단계 연속 nan/inf입니다. LEARNBOX_AMP=off 로 끄거나 학습률을 낮추세요."라고 멈춥니다. 이어서 재개할 수 있고, 재개할 때 정밀도를 `off`나 `fp32`로 바꿔 두면(환경변수 또는 설정) 그 값으로 다시 고릅니다. 정밀도를 직접 골라(웹 폼 `fp16`, `--amp fp16`) 시작한 작업은 그 값을 이어받으므로 `python -m learnbox resume-job <작업 번호> --amp off`로 이어서 하세요.
- 작업 카드와 모델 카드에 학습한 장치와 정밀도가 표시됩니다.

## 학습 장치 고르기

소형 AI·LoRA·자율 학습은 학습할 장치를 고를 수 있습니다. 기본은 `auto`(자동)입니다.

| 값 | 장치 | 준비 | 비고 |
|---|---|---|---|
| `auto` | 아래에서 쓸 수 있는 첫 장치 | | 순서: cuda → tpu → xpu → mps → cpu. TPU는 TPU 런타임 신호가 있을 때만 시도 |
| `cuda` | NVIDIA GPU, AMD GPU(ROCm) | CUDA용 PyTorch (Windows: `setup-gpu-windows.bat`). AMD는 Linux에서 ROCm용 PyTorch | AMD는 기기 카드에 "AMD ROCm"으로 표시, 미검증 |
| `tpu` | Google TPU (코랩 v5e-1) | 코랩은 기본 설치. 그 밖에는 `python -m learnbox.setup_accel` | 학습에만 사용, bf16 ([TPU로 학습](#tpu로-학습-코랩-tpu-v5e-1)) |
| `xpu` | Intel Arc GPU | XPU용 PyTorch (`setup-gpu-windows.bat`이 Arc를 찾으면 설치) | **미검증** |
| `mps` | Mac (Apple Silicon) | 기본 PyTorch | |
| `cpu` | CPU | | |

- **정하는 순서**: 학습 요청의 장치([학습] 탭 폼의 **장치** 선택, 명령줄 `--device`) → 환경변수 `LEARNBOX_DEVICE` → 설정 `training_device` → `auto`. 환경변수는 정밀도처럼 `serve`를 실행할 때 붙입니다.
- 웹 폼의 장치 선택(자동/GPU/TPU/Intel Arc/Mac/CPU)은 쓸 수 없는 장치를 고를 수 없게 하고, '자동' 옆에 실제로 쓸 장치를 보여 줍니다.
- 고른 장치를 쓸 수 없으면 CPU로 학습하고 이유를 모델 카드 안내에 남깁니다(예: "CUDA GPU를 찾지 못해 CPU로 학습했습니다.").
- 끊긴 학습을 **이어서 재개**하면 원래 장치를 이어받지 않고 **지금** 장치(위 순서)에서 이어 갑니다. 장치를 바꾸려면 `resume-job <작업 번호> --device tpu`.
- 자율 학습은 `autolearn start --device …`로 정한 값 → 환경변수 → 설정 → `auto` 순서입니다.
- `python -m learnbox device`의 '가속:' 줄에서 torch · torch_tpu · torch_xla · ROCm · xpu · TPU · 자동 선택 결과를 확인합니다.

### TPU로 학습 (코랩 TPU v5e-1)

- 코랩의 **v5e-1 TPU** 런타임(칩 1개, 메모리 16GB)에는 TPU 패키지 `torch_tpu`(TorchTPU)가 기본으로 설치되어 있습니다. **따로 설치하지 않아도** 서버를 켜면 TPU로 학습합니다. 순서는 [코랩 매뉴얼](docs/COLAB_MANUAL.md)을 보세요.
- LearnBox는 TPU를 `torch_tpu`로 먼저 열고, 안 되면 `torch_xla`(PyTorch/XLA)로 엽니다. `torch_xla`는 지원이 끝났습니다(2.9.0이 마지막). Python 3.10~3.12 TPU 런타임에서 `torch_tpu`를 쓸 수 없을 때만 씁니다.
- **torch를 따로 다시 설치하지 마세요.** `torch_tpu`는 지금 깔린 torch에 맞춰져 있습니다. 패키지가 없다는 안내가 나오면 `python -m learnbox.setup_accel`을 실행합니다.
- 정밀도는 항상 **bf16**입니다(fp16·기울기 스케일러 없음).
- **첫 학습은 컴파일 때문에 첫 단계가 몇 분** 걸릴 수 있습니다("TPU 컴파일 중(처음 한 번, 몇 분 걸릴 수 있음)"). 그 뒤로는 빠릅니다.
- **TPU는 한 프로세스만** 쓸 수 있습니다. 서버가 켜져 있을 때 다른 창이나 노트북 셀에서 학습 명령(`train-lora` 등)을 따로 실행하거나 `import torch`로 TPU를 쓰지 마세요. "다른 프로세스가 TPU를 쓰고 있습니다" 안내와 함께 CPU로 학습하거나 오류가 납니다. (`torch_tpu` 0.2.0은 `torch.manual_seed`만 불러도 칩을 잡습니다.)
- **답변은 TPU에서 하지 않습니다.** LoRA 답변과 소형 AI 이어 쓰기는 지금처럼 GPU/CPU에서 합니다.
- LoRA를 TPU(`torch_tpu`)에서 활성값 체크포인팅(메모리 절약)과 함께 학습하면 dropout을 끄고 안내합니다. TorchTPU의 알려진 문제로, 둘을 함께 쓰면 기울기가 틀리기 때문입니다.
- LoRA는 TPU에서만 배치를 문맥 길이(`seq_len`)까지 채워 모양을 고정합니다(다시 컴파일하지 않도록). GPU·CPU에서는 예전 그대로입니다.
- 소형 AI가 TPU 메모리를 넘으면 배치를 줄여 다시 시도하지 않고 "TPU 메모리가 부족해 학습을 멈췄습니다. 배치 크기·문맥 길이·모델 크기를 줄이세요."로 멈춥니다. 체크포인트에서 이어서 할 수 있습니다.
- `torch_xla`로 학습할 때 재컴파일 경고를 보려면 `LEARNBOX_XLA_DEBUG=1`을 붙입니다.

## 학습 일시정지 · 중간 저장 · 이어서 재개

몇 시간짜리 PC 학습(소형 AI · LoRA)이 저장장치 연결 끊김, 정전, 컴퓨터 재시작으로 처음부터 다시 하게 되지 않도록, 학습 중에 **중간 저장(체크포인트)** 을 남기고 끊긴 곳부터 **이어서 재개**합니다. 원할 때 **일시정지**했다가 다시 시작할 수도 있습니다.

**무엇을 저장하나**
- 소형 AI: 모델 가중치, 옵티마이저 상태, 학습률 위치(지금 단계), 난수 상태(다음에 뽑을 학습 배치 순서까지), 최근 손실, 학습 전 평가 손실, 누적 학습 시간, 글자 목록(어휘), 그리고 학습 설정(구조·단계·배치·학습률·seed·학습 자료 경로).
- LoRA: 어댑터 가중치, 옵티마이저 상태, 난수 상태, 손실 기록, 학습 설정(기반 모델·LoRA 설정·자료 경로 등).
- 그래서 이어서 한 결과는 끊기지 않았을 때와 같습니다(같은 PC·같은 자료면 가중치까지 같음). 마지막 저장 뒤에 진행한 단계만 다시 합니다.
- 체크포인트는 `<저장 위치>/job-<작업 번호>/`에 있고, 저장할 때마다 새로 다 쓴 뒤에 바꿔 끼우므로 **저장하는 도중에 끊겨도 직전 체크포인트는 온전**합니다.
- 크기는 모델 파일의 약 3배입니다(가중치 + 옵티마이저 상태). 베이스 크기 소형 AI는 약 330MB이고, 바꿔 끼우는 동안 잠깐 두 벌이 있으므로 그 두 배의 빈 공간이 필요합니다. LoRA는 어댑터만 저장해 작습니다.

**언제 저장하나** — 기본은 학습 **10분마다**(일시정지한 시간은 세지 않음)입니다. [관리] 탭 → 설정 → **학습 중간 저장**에서 바꿉니다.

| 항목 (`training_checkpoint`) | 기본값 | 설명 |
|---|---|---|
| 사용 (`enabled`) | 켜짐 | 끄면 중간 저장을 하지 않습니다(일시정지는 되지만 끊기면 처음부터) |
| 간격(분) (`every_minutes`) | 10 | 이 시간마다 저장. 0이면 시간 기준 저장 안 함 |
| 단계 간격 (`every_steps`) | 0 | N단계마다 저장. 0이면 단계 기준 저장 안 함. 둘 다 0이면 일시정지·끝내기·Ctrl+C 때만 저장 |
| 저장 위치 (`dir`) | 비어 있음 | 비우면 `데이터 폴더/checkpoints`. 전체 경로로 입력 |

명령줄 학습은 `--checkpoint-minutes N`으로 이번 학습의 간격만 바꿀 수 있습니다(0이면 시간 기준 저장을 끄고 Ctrl+C 때만 저장).

**외장 HDD에서 학습한다면** 저장 위치를 **내장 드라이브**로 지정하세요. 예: Windows `C:\LearnBox\checkpoints`, Mac `/Users/나/LearnBox/checkpoints`, Linux `/home/나/learnbox-checkpoints`. 외장 HDD가 빠져도 체크포인트는 내장 드라이브에 남습니다. 다만 이어서 할 때는 체크포인트에 기록된 학습 자료(`데이터 폴더/datasets/corpus-*`)를 다시 읽으므로 **외장 HDD를 같은 경로(같은 드라이브 문자)로 다시 연결한 뒤** 재개하세요. 자료가 없으면 "체크포인트에 기록된 학습 자료가 없습니다"라고 알려 줍니다.

**[작업] 탭의 학습 작업 카드** (버튼은 관리자에게만 보임, "마지막 저장: 3분 전 · 4500/6000단계" 표시)

| 진행 중 | **일시정지** · **지금까지 저장하고 끝내기** · 취소 |

- **일시정지**: 지금 단계를 마치고 저장한 뒤 멈춥니다. 멈춘 동안 다른 학습 작업은 차례를 기다리고, 수집·파일 가져오기는 계속됩니다.

- 학습이 끝나면(완료 또는 일찍 끝내기) 체크포인트는 자동으로 지워집니다.

**끊긴 뒤 이어서 하기**
- 서버가 꺼져 있는 동안(강제 종료·정전·PC 재시작) 화면 위쪽 표시가 **PC 연결 안 됨**으로 바뀌고 [작업] 탭 위에 "PC의 LearnBox에 연결할 수 없습니다. 아래는 마지막으로 받은 작업 상태입니다…" 안내가 뜹니다(카드의 '진행 중'은 끊기기 직전 상태). 로그인은 서버와 함께 끝나므로 서버를 다시 켜면 로그인 화면이 나옵니다.
- 서버를 다시 켜면 끝나지 못한 작업은 `중단됨`이 되고, 체크포인트가 있으면 "엔진이 재시작되어 중단됨 · 이어서 재개할 수 있습니다 (4500/6000단계)"로 표시되며 알림 종에 **학습이 중단되었습니다** 알림이 옵니다(누르면 [작업] 탭으로 이동).
- [작업] 탭에서 **이어서 재개**를 누르면 새 작업이 생겨 마지막 저장 지점 다음 단계부터 원래 목표 단계까지 학습합니다. 원래 설정(구조·단계·배치·학습률·seed·자료)을 그대로 쓰고 말뭉치를 새로 만들지 않습니다. 결과 모델의 단계 수는 원래 목표와 같고, 정보에 `resumed_from_step`(이어서 시작한 단계)과 `resumes`(이어서 한 횟수)가 남습니다.
- 학습이 오류로 **실패**해도 체크포인트가 남아 있으면 같은 방법으로 이어서 할 수 있습니다. 필요 없으면 **체크포인트 삭제**로 공간을 비우세요.
- 명령줄:
  ```
  python -m learnbox jobs                 # 최근 작업: 번호, 종류, 상태, 체크포인트 단계 (이어서 할 수 있으면 명령도 보여 줌)
  python -m learnbox resume-job <작업 번호>  # 체크포인트에서 이어서 (이 창에서 실행, 진행 출력)
  ```
  명령줄 학습(`train-tiny`, `train-lora`, `resume-job`) 중 Ctrl+C를 누르면 지금 단계를 마치고 저장한 뒤 멈추고 `python -m learnbox resume-job <번호>로 이어서 할 수 있습니다`라고 알려 줍니다.

**지원하지 않는 것**
- **자율 학습이 돌리는 학습**(`autolearn_train` 작업)은 일시정지·중간 저장·이어서 재개가 없습니다. 끊기면 그 회차의 학습은 잃고, 자율 학습이 계속 켜져 있으면 다음 학습 때 지난번에 완성된 모델에서 다시 이어 학습합니다. 오래 걸리는 학습은 [학습] 탭의 소형 AI / LoRA 학습으로 돌리세요.
- 휴대폰(브라우저) 학습은 이 기능과 별개로 자체 체크포인트를 씁니다([휴대폰에서 직접 학습](#휴대폰에서-직접-학습-온디바이스) 참고).
- 체크포인트에는 학습 자료의 전체 경로가 들어 있으므로 데이터 폴더를 다른 곳으로 옮기거나 다른 PC로 가져가서 이어서 할 수는 없습니다.
- GPU에서 저장하고 CPU에서 이어서 하는 것처럼 장치가 바뀌면 이어서는 되지만, 결과가 끊기지 않은 학습과 비트 단위로 같지는 않습니다. TPU에서도 체크포인트를 CPU 텐서로 저장하므로 TPU ↔ GPU ↔ CPU 사이에서 서로 이어서 할 수 있습니다. 장치가 바뀌면 LoRA 정밀도는 새 장치 기준으로 다시 고르고 안내합니다.
- 여러 번 끊겼다 이어서 할 수 있지만, 같은 체크포인트로 동시에 두 작업을 돌릴 수는 없습니다(이미 이어받은 작업이 있으면 그 작업에서 이어서 하세요).

## 휴대폰/PC 성능 차이 대응

**PC 쪽** (`python -m learnbox device`, [학습] 탭의 기기 카드): CPU 코어·메모리·GPU(NVIDIA CUDA · AMD ROCm · Intel Arc · Apple MPS)·TPU를 확인해 등급(PC CPU / PC GPU / 고성능 GPU / TPU)을 정하고 추천을 보여 줍니다. 기기 카드에는 TPU 줄(종류·메모리)과 `torch_tpu`/`torch_xla` 표시가 있고, TPU 런타임인데 패키지가 없으면 `setup_accel` 안내가 나옵니다.

| 등급 | 소형 AI 모델 | 주기당 단계 | LoRA 기반 모델 |
|---|---|---|---|
| PC CPU (메모리 6GB 미만) | 미니 | 300 | 권장 안 함 |
| PC CPU | 스몰 | 200 | 메모리 8GB 이상이면 0.5B (적은 단계로) |
| PC GPU (VRAM 6GB 이상) | 베이스 | 500 | 1.5B |
| 고성능 GPU (VRAM 16GB 이상) | 라지 | 1000 | 7B |
| TPU (GPU가 없고 TPU를 쓸 수 있을 때, 코랩 v5e-1 메모리 16GB) | 라지 | 1000 | 1.5B (측정 전까지, 3B는 메모리가 빠듯할 수 있음) |

- GPU 등급은 장치 종류와 관계없이 VRAM으로 정합니다. Intel Arc(`xpu`)와 AMD(ROCm)도 같은 표를 쓰지만 아직 실기기로 확인하지 못했습니다(미검증).
- LoRA 메모리 예상은 TPU에서 TPU 메모리(HBM) 기준입니다. `estimate --device tpu`는 "TPU 학습 가능: 예/아니오/측정 필요"를 보여 줍니다.

배치 크기는 메모리에 맞춰 줄어들고, 학습 스레드는 코어 수 − 1개를 씁니다(화면 응답용으로 1개 남김). GPU 메모리가 부족하면 배치를 절반으로 줄여 다시 시도합니다(TPU는 줄이지 않고 멈춤).

**휴대폰/브라우저 쪽** (이 기기의 메모리·코어·WebGPU로 자동 판단, [학습] 탭에서 확인):

| 등급 | 판단 | 자료 사본 | 생성 길이 | 모델 형식 | 실행 스레드(가능할 때) | 모델 크기 권장 |
|---|---|---|---|---|---|---|
| 저사양 | 메모리 3GB 이하 또는 4코어 이하 | 조각 1,500개 | 60자 | int8 | 1 | 8MB 이하 |
| 중급 | 그 밖 | 조각 6,000개 | 120자 | int8 | 2 | 40MB 이하 |
| 고사양 | 메모리 8GB 이상 + 8코어 이상 (또는 WebGPU 있는 PC) | 조각 30,000개 | 200자 | fp32 | 4 | 400MB 이하 |

브라우저가 여러 스레드를 허용하는 환경(교차 출처 격리)이 아니면 실행 스레드는 1개로 동작합니다. 휴대폰은 설정 없이도 모든 기능이 동작하며, 등급은 속도와 저장 크기만 조절합니다.

## 휴대폰에서 쓰기

1. PC에서 `serve --lan`으로 실행합니다.
2. 휴대폰을 PC와 **같은 Wi-Fi**에 연결하고, 출력된 주소로 접속해 로그인합니다.
3. [검색] 탭 → **이 기기에 저장 → 사본 받기**: 자료 사본(기기 성능에 맞는 크기)을 저장해 인터넷 없이 검색합니다.
4. [모델] 탭 → 소형 AI 모델의 **이 기기로 받기**(형식은 자동 또는 직접 선택) → **생성**: 휴대폰에서 직접 모델을 실행합니다. 처음 한 번은 실행 엔진(onnxruntime-web)을 인터넷에서 받습니다.
5. [검색] 탭에서 **온보드**를 고르면 PC에 연결되지 않아도 기기 안에서 검색하고 이어 쓰기 답변을 합니다.

**HTTPS가 필요한 경우**: 홈 화면에 앱으로 설치하거나, PC가 꺼진 상태에서도 화면을 여는 기능은 브라우저 정책상 HTTPS에서만 됩니다.
인증서가 있으면 `serve --lan --cert cert.pem --key key.pem`으로 실행하세요. 예를 들어 Tailscale을 쓰면 `tailscale cert`로 인증서를 받을 수 있고, 밖에서도 PC에 접속할 수 있습니다.
HTTP로 접속해도 자료 사본과 모델은 휴대폰에 저장되고 동작합니다.

## 휴대폰에서 직접 학습 (온디바이스)

휴대폰·태블릿 브라우저가 **글자 단위 나노급 GPT를 직접 학습**합니다. PC는 모델을 내려주고 결과를 받기만 하고, 계산은 기기의 웹 워커(`trainer.js`, 순수 JavaScript)가 합니다. 수학은 PC의 `tinylm.py`와 같아서(PyTorch와 손실·기울기 일치 확인) 결과를 PC에서 그대로 쓸 수 있습니다. 사용은 [학습] 탭의 **기기에서 학습** 카드에서 합니다 (모든 사용자 가능, 업로드만 관리자).

**한계**
- **나노급만** 가능합니다 (기본 파라미터 상한 200만 개, `mobile_training.max_params`). 미니 이상과 LoRA는 PC 전용입니다.
- 학습 중에는 **화면을 켜 둬야** 합니다. 브라우저가 백그라운드 탭의 계산을 늦추거나 멈춥니다(숨김 시 자동 일시정지 옵션 제공).
- 발열·배터리 보호: 느려지면 식힘 시간을 두고, 충전 중에만 학습/최저 배터리 기준을 정할 수 있습니다.
- **화면 꺼짐 방지(Wake Lock)는 HTTPS 같은 보안 컨텍스트에서만** 동작합니다. `http://192.168.x.x` 로 접속하면 쓸 수 없고, 앱이 안내 문구를 보여 줍니다. 이때는 화면 자동 꺼짐 시간을 직접 늘리세요. `serve --lan --cert --key` 로 HTTPS 를 쓰면 됩니다.

**사용 순서**
1. [검색] 탭에서 **이 기기에 저장 → 사본 받기**로 자료 사본을 먼저 저장합니다 (학습 말뭉치로 쓰입니다).
2. **벤치마크**: 몇 단계를 돌려 단계당 시간을 재고 "쾌적/보통/느림" 등급과 100·300단계 예상 시간을 보여 줍니다. 결과는 PC에 보고되어 감사 기록에 남습니다.
3. **이어서 학습**: PC 모델(.lbw 가중치를 내려받음)에서 이어가거나, **처음부터** 학습합니다 (처음부터는 저장된 자료의 글자로 어휘를 새로 만듭니다).
4. **체크포인트**: 기본 20단계마다 가중치·옵티마이저·난수 상태를 기기(IndexedDB)에 저장합니다. 탭을 닫거나 새로고침해도 "이어서 학습" 배너로 정확히 이어 갑니다. 중지해도 체크포인트는 남고, **지금까지로 마무리**로 결과를 만들 수 있습니다.
5. 결과(평가 손실 변화, 샘플 문장)를 보고 **이 기기 모델로 쓰기**(오프라인 생성), **.lbw 내려받기**, **PC로 올리기(관리자)** 중에서 고릅니다. 올린 모델은 PC 모델 목록에 `trained_on: device` 로 등록되고 ONNX(fp32·int8)가 자동으로 만들어집니다.

**.lbw 형식** (`LBWEIGHT` 8바이트 매직 + 버전 u32 + JSON 헤더 길이 u32 + JSON 헤더 + float32 리틀엔디언 텐서를 이어 붙인 순수 가중치 파일): 헤더에 `arch`(d_model·n_layer·n_head·seq_len·vocab_size), `itos`(글자 목록, 앞 4개는 특수 토큰), 텐서 이름·모양 목록, `parent`·`total_steps` 등 메타가 들어 있습니다. 가중치는 PyTorch 레이아웃(`[out, in]`)이라 `state_dict` 와 왕복됩니다. PC 모델의 `GET /api/models/<id>/files/model.lbw` 로 내려받고 `POST /api/models/upload`(관리자)로 올립니다. 올릴 때 서버가 NaN/Inf, 모양, 어휘, 파라미터 상한을 검증하고 하나라도 어긋나면 거부합니다.

## 자율 학습 (스스로 모으고 학습)

[학습] 탭의 **자율 학습** 카드(관리자) 또는 `python -m learnbox autolearn start`로 시작합니다.

**하는 일**
1. **수집**: 허용 시간대에만, 설정한 간격(기본 10분)마다 예약 목록에서 하나를 골라 조금(기본 5페이지)씩 수집합니다. 1시간에 가져올 페이지 상한(기본 60)이 있습니다.
2. **주제 찾기**: 예약 목록이 비었거나 한 바퀴 다 돌았으면, 최근 문서에서 자주 나오는 낱말로 새 검색 주제를 스스로 추가합니다(`자율` 표시, 최대 50개). 문서도 목록도 없으면 먼저 링크나 검색어를 넣거나 파일을 가져오세요.
3. **학습**: 새로 모인 글자가 기준(기본 2만 자) 이상이거나, 새 자료가 조금이라도 있고 정해진 간격(기본 60분)이 지나면 학습합니다. 학습 대상은 고를 수 있습니다.
   - 소형 AI 모델: 지난번 모델에서 **이어 학습**(구조가 같을 때). 크기는 시작할 때 정합니다(`자동`이면 이 PC 추천).
   - LoRA 모델: 지난번 어댑터에서 이어 학습
   - 의미 검색 색인: 새 부분만 추가
   - Q&A 학습 데이터: 온라인 모델로 만들어 LoRA 학습 전에 섞음 (온라인 모델이 켜져 있을 때만)
4. 허용 시간이 아니면 수집은 쉬고, `허용 시간이 아니어도 학습`을 켠 경우에만 학습합니다.
5. 한 대상이 실패해도 나머지는 계속하고, 실패는 알림으로 한 번만 알려 줍니다. 수동 작업이 돌고 있으면 그 작업이 끝날 때까지 기다립니다.

화면에는 현재 단계(대기/수집 중/학습 중/허용 시간 기다림/마무리 중), 수집 횟수·새 문서·새 글자·학습 횟수, 다음 수집/학습 확인 시각이 표시됩니다.

### 학습 종료와 결과 파일

**학습 종료** 버튼(또는 `python -m learnbox autolearn stop`)을 누르면 확인 뒤 다음 순서로 진행합니다.

1. 수집 중단, 새 자료가 있으면 마지막 학습
2. 지금까지 학습한 내용을 파일로 내보내기
3. (설정했다면) 외장 저장장치에도 복사
4. **알림**: 종 모양 알림에 "학습이 종료되었습니다"가 쌓이고, 화면에 안내(결과 보기 버튼)가 뜨고, 허용했다면 브라우저 알림도 옵니다. [학습] 탭에는 파일 목록과 크기가 있는 **결과 카드**가 나타납니다.

결과는 `data/results/learnbox-results-<날짜-시각>/` 폴더와 같은 이름의 **ZIP**으로 저장됩니다. 관리자는 [학습] 탭의 결과 카드/목록에서 ZIP이나 파일을 받을 수 있습니다(`GET /api/results/<이름>/download`).

```
learnbox-results-20261115-103000/
├─ REPORT.md              보고서(한국어): 기간, 수집한 쪽수·문서·글자(자료 종류별), 가져온 파일, 학습 기록(손실 전→후), 모델, 파일 사용법
├─ report.json            같은 내용을 프로그램이 읽기 좋게
├─ manifest.json          파일별 SHA-256 (확인: python -m learnbox verify <이 폴더>)
├─ documents/
│   ├─ documents.jsonl    문서 하나 = 한 줄 {id,url,title,source,query,fetched_at,chars,text}
│   ├─ documents.csv      엑셀용(UTF-8 BOM), 본문 포함
│   ├─ markdown/00001-제목.md   문서마다 마크다운 (맨 위에 title/url/source/fetched_at)
│   └─ all.txt            전체를 이어 붙인 텍스트
├─ corpus/                train.jsonl · eval.jsonl (학습에 쓴 말뭉치), qa.jsonl (Q&A 데이터가 있으면)
├─ index/learnbox.db      검색 인덱스(SQLite FTS5)와 임베딩이 든 전체 DB
└─ models/<모델 이름>/    model.onnx (fp32) · model.int8.onnx · model.pt · vocab.json · info.json (소형 AI), 어댑터 파일 (LoRA)
```

`자율 학습 기본값`의 `formats`(`jsonl`, `csv`, `md`, `txt`)로 내보낼 형식을 줄일 수 있고, `results_export_target`에 외장 저장장치 경로를 넣으면 종료할 때 폴더와 ZIP이 그곳에도 복사됩니다(공간과 쓰기 가능 여부를 먼저 확인).
`models/`의 `model.int8.onnx`와 `vocab.json`은 휴대폰 온보드에서 그대로 쓰는 파일입니다.

## 온라인 모델 설정 (Claude API)

**온라인 모델**은 검색된 자료 조각만 Claude에게 보내 답을 받습니다(인용 포함). 답변은 한국어이고, 자료에 답이 없으면 없다고 말하도록 지시합니다.

> **개인정보와 비용 주의**: 이 방식은 질문과 **검색된 자료 일부(문서 조각)가 Anthropic API 서버로 전송**됩니다. 개인정보나 외부에 보내면 안 되는 자료가 들어 있다면 쓰지 마세요(가져온 파일 포함). 호출마다 **API 사용 요금**이 듭니다. 사용자 PIN을 아는 사람은 누구나 온라인 모델로 질문할 수 있으니 PIN 공유에 주의하세요. 쓰지 않으려면 [관리] 탭에서 `온라인 모델`을 끄세요.

**키 설정** (먼저 찾은 것을 씁니다)
1. [관리] 탭 → 설정 → 온라인 모델 → **API 키** 입력 (저장 후에는 `********`로 가려 보이며, 감사 기록에도 남지 않습니다)
2. 환경변수 `ANTHROPIC_API_KEY`
3. `ant auth login` 등으로 만든 인증 프로필

**기본값** (`data/config.json`의 `online`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `enabled` | true | 끄면 온라인 모델과 Q&A 데이터 만들기를 쓸 수 없음 |
| `model` | `claude-opus-5-5` | 쓸 모델. 설정에서 바꿀 수 있음 |
| `effort` | `medium` | 깊이: low · medium · high · xhigh · max (높을수록 느리고 비쌈) |
| `max_context_chunks` | 8 | 한 번에 보내는 자료 조각 수 |
| `fallbacks` | true | **서버 측 대체 모델(fallbacks)** 사용 |

**서버 측 대체 모델**: `fallbacks`가 켜져 있으면 요청을 베타 엔드포인트(`server-side-fallback-2026-07-01`)로 보내며 `fallbacks="default"`를 지정합니다. 선택한 모델이 요청을 처리하지 못할 때 Anthropic 서버가 기본 대체 모델로 자동 재시도하므로, 클라이언트가 따로 다시 시도할 필요가 없습니다. 모델이 이 기능을 지원하지 않으면(지원 목록: `claude-opus-5-5` 등) 일반 호출로 보냅니다. 끄려면 `fallbacks`를 false로 하세요. 모델이 요청을 거절하면 오류 대신 "답을 만들지 못했습니다" 안내와 이유가 표시됩니다.

**Q&A 학습 데이터 만들기**: [학습] 탭의 버튼 또는 `python -m learnbox build-qa`. 자료 조각마다 온라인 모델에게 한국어 질문·답변 쌍을 만들게 해 `data/datasets/qa.jsonl`에 쌓고(이미 쓴 조각은 건너뜀), LoRA 학습에 섞어 씁니다. 이 역시 자료가 API로 전송되고 비용이 듭니다. 키/권한 오류처럼 다시 해도 소용없는 오류는 바로 멈춥니다.

## 명령줄

```
python -m learnbox init | serve | status
python -m learnbox collect <URL...> [--depth 1]
python -m learnbox websearch "검색어"
python -m learnbox ingest <파일 또는 폴더>
python -m learnbox search "검색어" [--sources file,link] [--mode hybrid|keyword|semantic] [--limit N] [--offset N]
python -m learnbox ask "질문" [--engine search|tiny|lora|online] [--model-id N]
python -m learnbox estimate [--preset nano|mini|small|base|large|custom] [--d-model N --n-layer N --n-head N --seq-len N --vocab-size N] [--batch-size N] [--device 장치]
python -m learnbox estimate --kind lora [--base-model ID] [--lora-r N] [--seq-len N] [--batch-size N] [--device 장치]
python -m learnbox device [--json]
python -m learnbox train-tiny [--preset ...] [--d-model ...] [--steps N] [--batch-size N] [--lr X] [--resume 모델번호] [--checkpoint-minutes N] [--device 장치]
python -m learnbox train-lora [--base-model ID] [--lora-r N] [--max-steps N] [--seq-len N] [--resume 모델번호] [--no-qa] [--checkpoint-minutes N] [--device 장치] [--amp auto|fp16|off|fp32]
python -m learnbox jobs [--limit N] | resume-job <작업 번호> [--device 장치]
python -m learnbox index-embeddings
python -m learnbox build-qa [--limit-chunks N] [--per-chunk N]
python -m learnbox autolearn start [--targets tiny,lora,embeddings,qa] [--tiny-preset ...] [--steps-per-cycle N] [--device 장치] ...
python -m learnbox autolearn status | stop | run [--start] [--until-end] [--stop-after 초] [--interval 초] [--device 장치]
python -m learnbox results | models
python -m learnbox drives | export <경로> | verify <폴더> | import <폴더>
python -m learnbox.setup_accel [--check] [--dry-run] [--force] [--backend auto|torch_tpu|torch_xla] [--torch-build]
```

- `--device`는 `auto`(기본) · `cuda` · `tpu` · `xpu` · `mps` · `cpu`입니다([학습 장치 고르기](#학습-장치-고르기)). `gpu`·`rocm`→`cuda`, `arc`→`xpu`, `mac`→`mps` 같은 별칭도 받습니다. `resume-job`은 주지 않으면 지금 장치에서 이어 갑니다.
- `--amp`는 LoRA 정밀도입니다([정밀도 (LoRA)](#lora-학습-공개-모델--내-자료)).
- `device`는 '가속:' 줄에 torch · torch_tpu · torch_xla · ROCm · xpu · TPU · 자동 선택 결과를 보여 줍니다.
- `setup_accel`은 TPU 런타임일 때만 TPU 패키지를 설치하고, `--torch-build`는 이 PC의 GPU에 맞는 PyTorch 설치 명령을 알려 줍니다([설치와 실행](#설치와-실행-pc)).

- 학습 명령은 Ctrl+C를 누르면 지금 단계를 마치고 중간 저장한 뒤 멈추며, `resume-job <작업 번호>`로 이어서 합니다([학습 일시정지 · 중간 저장 · 이어서 재개](#학습-일시정지--중간-저장--이어서-재개)).
- `train-mobile`, `train-pc`는 `train-tiny`, `train-lora`의 이전 이름으로 그대로 동작합니다.
- `autolearn run`은 서버 없이 이 창에서 자율 학습을 직접 돌립니다(Ctrl+C로 멈춤, 세션은 남음). **서버(`serve`)와 같은 데이터 폴더에 동시에 쓰지 마세요.** `autolearn stop`은 마지막 학습과 결과 내보내기가 끝날 때까지 기다립니다.
- 데이터 폴더는 기본 `./data`이며 `--data` 또는 `LEARNBOX_DATA` 환경변수로 바꿉니다.
- 환경변수 `LEARNBOX_DEVICE`(학습 장치)와 `LEARNBOX_AMP`(LoRA 정밀도)는 학습 요청에 값이 없을 때 설정보다 먼저 쓰입니다. 웹에서 시작하는 학습에 적용하려면 `serve`를 실행할 때 붙이세요.

## 법적·윤리적 주의

- 사이트 **이용약관**을 확인하세요. robots.txt를 지켜도 약관상 수집이 금지된 곳이 있습니다.
- 수집한 글의 **저작권**은 원저작자에게 있습니다. 개인 학습·연구 용도로 쓰고, 원문을 재배포하지 마세요. 위키백과 글은 CC BY-SA입니다. **학습 종료 결과 파일(문서 JSONL/CSV/마크다운, ZIP)에는 수집한 원문이 그대로 들어 있으니** 다른 사람에게 주거나 올리기 전에 권리를 확인하세요.
- **개인정보**가 포함된 페이지는 수집하지 않도록 허용 도메인을 설정하세요. 내가 가져오는 파일에 개인정보가 있으면 검색 결과·결과 파일·온라인 모델 전송에 그대로 포함됩니다.
- **온라인 모델**을 쓰면 검색된 자료 일부가 Anthropic API로 전송되고 비용이 발생합니다. 내용에 대한 책임은 사용자에게 있습니다.
- **모델 라이선스**: LoRA 기반 모델(예: Qwen2.5-3B는 비상업)과 임베딩 모델의 라이선스를 확인하세요. 내 자료로 학습한 모델은 그 자료의 권리 제한을 함께 받는다고 보는 것이 안전합니다.
