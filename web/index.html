      학습은 관리자만 시작할 수 있습니다. 진행 상황은 누구나 [작업] 탭에서 볼 수 있습니다.

      PC용 모델 학습 (LoRA)

      공개 소형 모델에 수집 자료를 추가 학습합니다. GPU가 있으면 자동으로 사용합니다. CPU만 있으면 매우 느립니다.

      휴대폰용 초소형 모델 학습 (저사양)

      CPU로 학습 가능한 수백만 파라미터 모델입니다. 휴대폰 브라우저에서 직접 실행됩니다. 문장 흉내 수준이며 사실 답변용은 아닙니다.
