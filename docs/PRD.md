# LearnBox PRD (제품 요구사항 문서)

- 상태: 초안 (검토 전, 빌드·배포 없음)
- 대상 버전: LearnBox v2
- 관련 문서: `docs/SPEC.md`(구현 계약), `README.md`(사용법)

---

## 1. 배경과 목표

개인이 인터넷 자료와 자기 파일을 모아 **내 자료로 학습한 AI**를 PC와 휴대폰에서 쓰고 싶다. 자료는 허용된 시간대에만 조금씩 모으고, 학습 결과는 관리자가 외장 저장장치에 보관한다.

**목표**
1. 자료를 검색하고, 자료 근거의 답을 받는다.
2. 모델 크기와 답변 방식을 사용자가 고른다.
3. PC와 휴대폰이 같은 화면과 데이터를 공유한다.
4. 학습 결과를 파일로 내보내고 외장 저장장치에 보관한다.

**성공 지표 (초안)**
- 자료 업로드 후 검색 결과가 나오기까지 1초 이내 (키워드 검색, 자료 1만 건 기준)
- 모델 크기를 입력하면 0.5초 이내에 파일 크기·메모리·기기 적합성이 표시됨
- 학습 종료 후 결과 ZIP 다운로드까지 사용자 조작 3번 이내
- 휴대폰에서 온보드 검색이 인터넷 없이 동작

## 2. 사용자와 권한

| 역할 | 할 수 있는 것 |
|---|---|
| 사용자 (사용자 PIN) | 검색, 질문, 자료 업로드, 수집 요청, 진행 상황 보기, 모델 실행 |
| 관리자 (관리자 PIN) | 사용자 권한 전부 + 학습 시작·중지, 자율 학습, 내보내기, 설정, 문서 삭제, 감사 기록 |

관리자 PIN으로 로그인한 기기에서만 학습과 내보내기를 시작할 수 있다.

## 3. 범위

**포함**
- 답변 방식 5가지 (4개 모델 + 검색만)
- 모델 크기 설정 (프리셋 5단계 + 직접 설정)
- 자료 수집(링크, 실시간 검색), 파일 가져오기, 자율 학습, 학습 종료와 결과 내보내기
- PC 웹 서버 + 휴대폰 브라우저 화면 (같은 화면)

**제외 (이번 버전)**
- 휴대폰에서의 학습 (실행만 지원)
- 로그인 계정 여러 개, 권한 세분화
- 클라우드 호스팅, 인터넷 공개 배포
- 여러 사람이 같은 자료를 동시에 편집하는 기능

## 4. 답변 방식 (5가지)

| 번호 | 이름 | 실행 위치 | 답변 방식 | 필요한 것 | 제한 |
|---|---|---|---|---|---|
| A | **소형 AI 모델** | PC 서버 | 자료로 처음부터 학습한 글자 단위 모델이 이어 쓴 문장 + 자료의 핵심 문장 | 학습 1회 (수 분~수십 분) | 사실 답변 능력 없음. 문장 흉내 수준 |
| B | **LoRA 모델** | PC 서버 (GPU 권장) | 공개 소형 모델(0.5B~7B)에 자료를 추가 학습한 모델이 검색된 자료를 근거로 답하고 출처 [n] 표시 | 기반 모델 다운로드 (0.5B 약 1GB), GPU 권장 | CPU만 있으면 매우 느림 |
| C | **온라인 모델 (Claude)** | Anthropic 서버 | 검색된 자료 조각을 문서로 보내고, 인용과 함께 답변 | API 키, 인터넷 | 검색된 자료 일부가 외부 API로 전송됨. 비용 발생 |
| D | **온보드 모델** | 휴대폰/PC 브라우저 안 | 내려받은 소형 모델(ONNX, int8 또는 fp32)을 브라우저에서 실행. 오프라인 검색 + 핵심 문장 | 모델 파일 다운로드 (한 번) | 글자 단위 모델이라 사실 답변 불가. 단일 스레드 |
| E | **검색만** | PC 서버 또는 브라우저 | 키워드·의미·통합 검색 결과와 핵심 문장, 문서 보기 | 없음 | 생성 답변 없음 |

**요구사항**
- R-A-1: 질문 하나에 대해 검색 근거(출처 목록)를 항상 함께 보여 준다.
- R-B-1: 자료에 답이 없으면 "자료에 없습니다"라고 답한다.
- R-C-1: 온라인 모델 사용 전 "자료 일부가 외부로 전송된다"는 안내를 보여 준다.
- R-C-2: API 키는 화면에서 가려서 보이고, 감사 기록에 남지 않는다.
- R-D-1: 휴대폰 등급(저/중/고)에 따라 int8 또는 fp32와 생성 길이를 자동으로 고른다.
- R-E-1: 검색어가 3글자 미만이면 부분 일치(LIKE)로 처리한다.

**답변 엔진 선택 흐름**
1. 사용자가 답변 방식을 고른다 (기본값: 검색만).
2. 모델이 필요한 방식인데 모델이 없으면, 이유와 준비 방법을 한국어로 안내한다.
3. 온라인 모델에서 키가 없으면 "사용할 수 없음"(503)으로 안내하고 검색 결과는 그대로 보여 준다.

## 5. 모델 크기 설정

### 5.1 프리셋

| 이름 | 용도 대상 | 차원(d_model) | 레이어 | 헤드 | 길이(seq) | 어휘 | 대략 파라미터 |
|---|---|---|---|---|---|---|---|
| 나노 (nano) | 저사양 휴대폰 | 128 | 2 | 4 | 128 | 2,000 | 약 67만 |
| 미니 (mini) | 고사양 휴대폰 | 256 | 4 | 4 | 192 | 3,000 | 약 400만 |
| 스몰 (small) | PC CPU | 384 | 6 | 6 | 256 | 4,000 | 약 1,000만 이상 |
| 베이스 (base) | PC GPU | 512 | 8 | 8 | 384 | 6,000 | 약 3,000만 이상 |
| 라지 (large) | 고성능 GPU | 768 | 12 | 12 | 512 | 8,000 | 약 7,000만 이상 |

- 프리셋 값은 추정치입니다. 실제 크기는 입력 시 화면에 표시되는 값을 따릅니다.
- LoRA 기반 모델은 별도로 고른다 (0.5B, 1.5B, 3B, 7B).

### 5.2 직접 설정

- 입력 항목: d_model, n_layer, n_head, seq_len, vocab_size, 학습 단계 수, 배치 크기
- 허용 범위: d_model 32~2048, n_layer 1~48, n_head 1~32, seq_len 16~2048, vocab_size 100~20000
- 규칙: d_model은 n_head로 나누어떨어져야 한다. 어기면 "d_model은 n_head로 나누어떨어져야 합니다 (d_model=…, n_head=…)" 오류.
- 비워 두거나 0을 넣으면 프리셋 값을 쓴다.

### 5.3 입력 즉시 보여 주는 정보

값을 바꾸면 **디바운스 후 0.5초 이내**에 아래를 표시한다.

| 항목 | 표시 예시 | 계산 |
|---|---|---|
| 파라미터 수 | "약 40만 개" | V·d + T·d + L·(12d² + 13d) + 2d |
| 파일 크기 | "fp32 1.6MB / int8 0.5MB" | 파라미터 × 4바이트 (fp32), × 1바이트 (int8) |
| 학습 메모리 | "약 87MB" | 파라미터 × 16바이트 + 배치 활성값 |
| 실행 메모리 | "약 N MB" | 파라미터 × 1바이트 (int8 기준) + 캐시 |
| 적합 기기 | 아래 표의 배지 | 기기 등급별 메모리·속도 기준 |

**기기 적합 배지 기준 (초안)**

| 기기 등급 | 기준 | 적합 판정 예 |
|---|---|---|
| 휴대폰 저사양 | 메모리 3GB 이하 또는 코어 4개 이하 | 나노 |
| 휴대폰 고사양 | 메모리 8GB 이상 | 미니 |
| PC CPU | 그래픽카드 없음 | 스몰 |
| PC GPU | VRAM 6GB 이상 | 베이스 |
| PC 고성능 GPU | VRAM 16GB 이상 | 라지 |

- 기준을 넘으면 초록 배지, 경계에 가까우면 노랑, 넘으면 빨강으로 표시한다.
- 빨강이어도 저장하고 학습을 막지는 않는다. 대신 "이 기기에서는 느리거나 실행이 어려울 수 있다"는 경고를 보인다.
- 잘못된 값은 저장 버튼을 비활성화하고 입력 칸 아래에 사유를 보인다.

**요구사항**
- R-S-1: 프리셋 선택과 직접 설정 값이 충돌하면 직접 설정 값을 우선한다.
- R-S-2: 추정치와 실제 학습 후 파일 크기의 차이는 ±1% 이내여야 한다 (fp32, int8 파일 기준).
- R-S-3: 추정 API(`POST /api/estimate`)는 인증된 사용자만 호출할 수 있다.

| 항목 | PC | 휴대폰 |

## 7. 자료 수집과 자율 학습

- **허용 시간대**: 요일과 시각 구간을 여러 개 설정할 수 있다. 자정을 넘는 구간도 지원한다. 모든 요청 직전에 시간을 확인한다.
- **수집 예절**: robots.txt를 따르고, 같은 사이트 요청 사이에 간격(기본 3초)을 두며, 내부망 주소는 차단한다.
- **자율 학습**: 허용 시간대에 예약 목록에서 조금씩 수집하고, 주제가 없으면 자료에서 주제를 찾는다. 새 글자가 기준치를 넘으면 다시 학습한다.
- **학습 종료**: 마지막 학습 한 번 → 결과 내보내기(문서 jsonl·csv·md·txt, 말뭉치, 검색 인덱스, 모델, REPORT.md, manifest.json, ZIP) → 알림.

**요구사항**
- R-C-3: 허용 시간 밖에서는 수집을 시작하지 않고, 진행 중이던 수집은 즉시 멈춘다.
- R-C-4: 학습 종료 알림에는 결과 폴더 이름과 파일 수가 들어간다.

## 8. 검색 기능

- 키워드 검색(한국어 부분 일치), 의미 검색(임베딩), 통합 검색(두 결과를 순위로 합침)
- 구문 검색 `"인공 신경망"`, 제외 검색 `-요리`
- 출처 필터(웹, 검색 수집, 파일, 자율)
- 문서 보기: 전체 본문, 일치 위치 강조, 이전/다음 이동

## 9. 비기능 요구사항

- **보안**: PIN 해시 저장, 로그인 실패 제한(5분에 8회), 세션 토큰 12시간, 설정 파일의 PIN·API 키 제외 후 내보내기.
- **개인정보**: 자료가 외부로 나가는 경로는 온라인 모델 한 가지뿐이며, 그 사실을 화면에 안내한다.
- **성능**: 자료 1만 건까지 검색 응답 1초 이내 (키워드 기준).
- **신뢰성**: 한 학습 대상이 실패해도 나머지 대상은 계속 진행한다. 작업이 중단되면 "중단됨"으로 표시한다.
- **이식성**: Windows, macOS, Linux에서 실행되고, 휴대폰은 최신 Chrome과 Safari를 지원한다.

## 11. 열린 질문 (결정 필요)

1. 온라인 모델 기본값을 켜 둘지 끌지 (현재: 키가 있을 때만 사용 가능)
2. 소형 AI의 기본 프리셋을 기기 등급에 따라 자동 선택할지, 항상 수동으로 고르게 할지
3. 자율 학습의 기본 학습 주기 (현재 60분)
4. 자료 보관 기간 정책 (자동 삭제 여부)
5. HTTPS 인증서를 기본 제공할지 (휴대폰 홈 화면 설치와 오프라인 동작에 필요)

## 12. 용어

- **LoRA**: 큰 모델은 그대로 두고 작은 보정 부품만 추가로 학습하는 방법
- **ONNX**: 여러 환경에서 같은 모델을 실행하는 표준 파일 형식
- **int8**: 숫자를 1바이트로 줄인 경량 형식. 파일이 약 4분의 1 크기가 된다
- **임베딩**: 문장을 숫자 벡터로 바꿔 뜻이 비슷한 문장을 찾는 방식
- **FTS5 trigram**: 글자 세 개 단위로 찾는 전문 검색 인덱스. 한국어 부분 일치에 쓴다
